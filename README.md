# Ras Almal

Ras Almal هو مشروع لعبة محاكاة أعمال واستثمار متكامل. يتيح للاعب بناء إمبراطورية من الثروة عبر الوظائف والمشاريع والأسهم والسمعة.

## المميزات الحالية

- لوحة تحكم رئيسية للاعب
- نظام مستويات XP
- رواتب وبدائل الوظائف
- شراء الشركات ودخل سلبي
- سوق الأسهم
- لوح ترتيب للاعبين
- لوحة تحكم للمشرف
- هيكل قاعدة بيانات Prisma
- تصميم عربي RTL

## المميزات القادمة

- تسجيل دخول/تسجيل مستخدمين حقيقيين
- JWT/Auth sessions
- قاعدة بيانات PostgreSQL كاملة
- عمليات مالية آمنة عبر transactions
- إشعارات وإعلانات داخل التطبيق
- لاعبين متعددون مع أوضاع جماعية
- وحدة إدارة المستخدمين والربح

## التشغيل المحلي

1. تثبيت الحزم:

```bash
npm install
```

2. إعداد قاعدة البيانات SQLite (للتطوير):

```bash
npx prisma generate
npx prisma db push
npx prisma db seed
```

3. تشغيل التطبيق:

```bash
npm run dev
```

4. افتح المتصفح على:

```text
http://localhost:3000
```

## البنية الرئيسية

- `app/` — صفحات التطبيق
- `components/` — مكونات UI
- `lib/` — منطق اللعبة
- `prisma/` — مخطط قاعدة البيانات وبيانات أولية
